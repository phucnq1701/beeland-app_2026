# Inventory A: Products / Projects / Price / PriceSheet / Filter (beeland-app_2026)

Scope: `sevicesSupabase/ProductService.ts`, `ProjectService.ts`, `PriceServices.ts`, `PriceSheetService.ts`, `FilterService.ts`,
`components/priceSheet/ProductPicker.tsx`, and the lib helpers they use (`lib/projectScope.ts`, `lib/priceSheetPayload.ts`
(mapProductRow/buildSaveRow), `lib/bookingPrice.ts` (sortPriceLists)). `lib/listRpc.ts`, `lib/productOverview.ts`,
`lib/productStatus.ts`, `lib/productRealtime.ts`, `lib/priceSheet*.ts` make **no** network calls; they only shape/consume results
(the fields they read are listed in the "fields used" column).
`ProductPicker.tsx` makes no direct calls (uses ProjectService.getProjects + ProductService.getProducts → rows 2/3/11/12).
`getValidSupabaseJwt` / `getCompanyId` / `getTypeAccount` (cloudTenant) read local storage only — no network.

All calls go through `axiosApiSupabase` (base `https://api-beeland26.beesky.vn`). Total **39 distinct network call sites**
(several fire multiple times per user action — see "calls per action" at the bottom).

Legend: R = read, W = write. "REST table" = direct table read via `rest/v1/<table>` (all of these must become app endpoints).
